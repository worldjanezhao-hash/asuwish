# 心愿养成所 · Wish Garden

帮助用户记录心愿储蓄、观察指定二手商品挂牌价，并参考历史记录选择购买时机。

## 项目结构

- `wish-site/`：独立网页，包含心愿、储蓄记录、进度场景、商品历史和监测设置。
- `wish-extension/`：Chrome/Edge 扩展，读取商品页面，执行定时检查，保存记录并通知。

## 本地运行

1. 浏览器打开 `chrome://extensions`，开启开发者模式，加载 `wish-extension/` 文件夹。
2. 双击 `wish-site/start.command`，或执行：

   ```sh
   python3 -m http.server 8765 --bind 127.0.0.1 --directory wish-site
   ```

3. 打开 http://localhost:8765 ，创建心愿，在价格监测页面添加商品。

网站通过仅允许本地地址的扩展通信桥访问数据。扩展更新后需重新加载，并刷新网站。

## 当前能力与边界

支持储蓄存入和取出、进度场景、价格历史、目标价提醒和本地备份。数据保存在浏览器扩展，尚无账号或云端同步。

每日检查需要电脑及浏览器运行。休眠或关机期间无法执行；恢复后补查当天任务。解析依赖页面结构，自动价格应核对；失败不会被记为下架。价格建议仅参考已记录挂牌价，不能代表成交价或未来最低价。

自动获取平台数据需要确认平台许可。当前项目不调用隐藏接口、不读取 Cookie、不绕过验证。

## GitHub Pages

可托管 `wish-site/` 静态页面。部署前必须把扩展的网站匹配地址和后台来源检查配置为实际站点，并限制到本项目路径。目前桥接仅支持 localhost，直接上线不会自动连接扩展。

## 数据保护

仓库只保存代码。个人记录与备份、Cookie、令牌和环境密钥不应提交。
