心愿价格记录 0.2.0

安装或更新
Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
首次安装：开启开发者模式，加载已解压的扩展程序，选择本文件夹。
已有安装：在扩展卡片点击重新加载。此次新增闲鱼站点、定时器、通知权限，浏览器可能要求重新启用或确认权限。

每日监测
点击扩展的“每日监测设置”，添加完整 https://www.goofish.com/item?id=... 商品链接。
设置每日时间（电脑本地时间）、可选目标价，保存设置。
先点击“立即检查全部商品”检查解析结果。扩展逐个打开后台标签页，每件最多等待约20秒，结束后关闭自己创建的标签页。
每天指定时间后检查一次；一分钟调度可能受浏览器节流影响，不保证精确到分钟。
电脑休眠或浏览器关闭时无法执行。恢复后补查当天已经到时、尚未尝试的任务，不补造过去几天的数据。
失败不会自动不断重试。请手动打开商品完成登录/验证，再点击立即检查。
手动停止监测会保留历史记录。导出全部记录包含商品列表、设置、价格快照。

通知与状态
比上次价格降低，或首次达到目标价时发出浏览器通知。系统需允许浏览器通知。
自动记录明确标记未经人工确认；解析错误也可能导致错误价格提醒，需要核对商品页。
读取失败、页面关闭或登录异常不会被记为下架，不会写入虚假价格。
下架状态尚未自动识别。

数据与权限
所有记录保存在该浏览器配置的扩展本地存储，删除扩展可能丢失记录，请定期导出。
后台调度只访问用户加入列表的闲鱼商品链接，不调用隐藏API、不读取Cookie、不绕过验证。
技术实现不代表取得平台数据使用许可；公开运营需要确认平台授权。

验证范围
配置与静态文件检查已完成。当前开发环境的Node与浏览器运行时存在系统兼容问题，无法在这里完成真实浏览器端到端验证。
解析器依赖商品页面结构，后台标签页是否正常渲染需要用实际商品验证，不能承诺长期稳定读取。
